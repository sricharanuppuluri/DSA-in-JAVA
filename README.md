# DSA-in-JAVA


A collection of **Data Structures and Algorithms** implemented in Java.  
This repository is designed for **students, interview preparation, and coding practice**.

---

## 📘 Contents
- Arrays  
- Linked Lists  
- Stacks & Queues  
- Hash Tables  
- Trees (Binary Tree, BST, etc.)  
- Graphs (DFS, BFS, Shortest Path)  
- Searching & Sorting Algorithms  
- Recursion & Dynamic Programming  
- Greedy Algorithms  

---

## 🚀 Getting Started

### Prerequisites
- Install **Java JDK 8+**  
- Install any IDE (e.g., IntelliJ IDEA, Eclipse, VS Code with Java extension)  

### ▶️ How to Run the Code
#1. Navigate to the project folder:
   ```bash
   cd DSA-in-JAVA
   ```
#2. Compile the Java file
javac FileName.java

Replace FileName.java with the actual file you want to run.
Example: javac BubbleSort.java

#3. Run the compiled program
java FileName

Example: java BubbleSort

#4. View the output
The program will execute and display the results in the terminal.
